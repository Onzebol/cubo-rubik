# Cubo Rubik — aprende a resolverlo

Web mobile-first para aprender a resolver el cubo de Rubik 3x3 con el método por capas (el de principiantes).

Stack: Vite + React + TypeScript · tests con Vitest (TDD) · despliegue en GitHub Pages.

```
npm install
npm run dev     # desarrollo
npm test        # tests
npm run build   # producción
```

Flujo: toda mejora parte de una issue y entra por PR (`Closes #n`).
