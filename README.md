# CuboFácil — aprende a resolver el cubo de Rubik

Web mobile-first con el **método por capas de la guía oficial de Rubik's** (copia en `docs/Rubiks-3x3-Solve-Guide.pdf`). Cada paso tiene su explicación y un **cubo 3D animado** que reproduce los algoritmos movimiento a movimiento (arrastra el cubo para girar la vista). Incluye modo práctica con mezcla aleatoria y progreso guardado en el navegador.

Stack: Vite + React + TypeScript · Vitest (TDD) · GitHub Pages.

```
npm install
npm run dev     # desarrollo
npm test        # tests
npm run build   # producción
```

Flujo: toda mejora parte de una issue y entra por PR (`Closes #n`).
